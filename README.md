# 🐍 Mambatinder — генератор карточек

Веб-приложение, которое делает картинки с заданным текстом. Холст сам
подстраивается под текст: **Enter** — рост в высоту, длинная строка — рост
в ширину. Текст всегда по центру.

- Белый фон с регулируемой плёночной зернистостью
- Шрифт **Montserrat ExtraBold**, цвет `#855F82`
- Эмодзи в стиле Telegram (Twemoji SVG)
- Змея снизу по центру (загрузка своего изображения), нижний край всегда
  совпадает с краем шаблона, размер — ползунком
- Подписи `@mambatinder` с иконками Telegram (слева) и VK (справа), серый
  цвет, адаптивная центровка и размер
- Ползунок итогового разрешения JPG (ограничивает большую сторону файла)
- Сохранение в JPG: кнопка или `Ctrl+S`

## Локальный запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # сборка в папку dist/
```

## Загрузка на GitHub

1. Создайте пустой репозиторий на [github.com/new](https://github.com/new).
2. В папке проекта выполните:

```bash
git init
git add .
git commit -m "Mambatinder card generator"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПО.git
git push -u origin main
```

### Публикация на GitHub Pages (автоматически)

В репозитории уже настроен workflow `.github/workflows/deploy.yml`:

1. Откройте **Settings → Pages**.
2. В поле **Source** выберите **GitHub Actions**.
3. После каждого `git push` сайт будет пересобираться и публиковаться по
   адресу `https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПО/`.

### Быстрый вариант без Pages (только код)

Просто загрузите файлы репозитория через веб-интерфейс GitHub
(**Add file → Upload files**) — workflow и инструкция уже в комплекте.

### Готовая статическая версия

Скомпилированная версия лежит в папке `dist/` (index.html + ассеты,
относительные пути — работает с любого хостинга и файловой системы).
